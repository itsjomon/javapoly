# Loops

- While
- For
- Do While

## While Loop

```java
while (condition) {
    // do something
}
```

## For Loop

```java
for (initialization; condition; update) {
    // do something
}
```

## Do While Loop

```java
do {
    // do something
} while (condition);
```

## Break Statement

To exit the loop

```java
break;
```

## Continue Statement

To skip an iteration

```java
continue;
```
